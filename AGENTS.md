# Project orientation

For KNL Consumable ERP work, read [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md)
for the saved code/workflow review and recent owner-approved changes. Follow the
mandatory project-document read order in [docs/README.md](docs/README.md).

The context document is a dated snapshot, not a replacement for current code,
company-approved rules or the user's instructions. Recheck changed code and relevant
contracts before relying on it. Record verified workflow changes there when relevant;
never store credentials or sensitive employee information in project memory.
